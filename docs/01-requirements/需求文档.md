# 需求文档

> 项目：Markdown 预览器（md-preview）
> 版本：v1.3（Web + 桌面）
> 状态：已实现并通过验收

---

## 1. 一句话需求

给需要读 Markdown 的人一个**打开就能看**的本地阅读器：把 `.md` 文件或整个文档目录交给它，立刻得到规范、可读、安全的渲染结果；需要改两笔时，也能就地改、就地存。

## 2. 用户与场景

| 角色 | 典型场景 | 真正在意什么 |
| --- | --- | --- |
| 开发者 | 改完 README / 设计稿，想立刻确认排版 | 打开快、渲染准、改完不用重开 |
| 文档维护者 | 浏览一整个 `docs/` 目录，在不同文件间跳 | 目录结构清楚、多篇同时开着、能快速定位小节 |
| 偶尔使用的人 | 收到一个 `.md` 文件，只想读一遍 | 零安装、不申请权限、不往外传数据 |

三个角色共享同一条底线：**不要为了「看一眼」去装一个 IDE 或启动一整套工具链。**

## 3. 范围

### 3.1 本期做（v1.3）

- 单个 `.md` 文件的打开与预览
- 整个目录的打开、文档列表、按目录分组，**只收 Markdown 文件**
- CommonMark + GFM 的准确渲染
- 代码高亮、表格、任务列表、脚注、Mermaid 图表、**KaTeX 数学公式**
- 大纲、滚动联动、点击跳转
- **多标签页：同时打开多篇，各自保留滚动位置与未保存状态**
- **刷新后恢复上次的标签页（含滚动位置）**
- **批量关闭：关闭其他标签 / 全部关闭**
- **文件监听：磁盘上的文档被修改后自动刷新**
- **双栏编辑：左源码右预览，滚动同步，可保存回文件**
- 主题 / 字号 / 阅读宽度，偏好本地保存
- **桌面版：双击 exe 即可用，可关联 .md，支持命令行打开**

### 3.2 本期明确不做

| 不做 | 原因 |
| --- | --- |
| 新建文档、重命名、删除文件 | 属于文件管理器的职责 |
| 语法高亮编辑器、自动补全、多光标 | 编辑器内核不在本项目范围内，保持 textarea 的轻量 |
| 撤销栈与协同编辑 | 双栏编辑定位是「顺手改两笔」，不是长期写作 |
| 导出 PDF / HTML | 浏览器自带打印已够用（`Ctrl+P`），样式已做打印适配 |
| 账号、云同步、分享链接 | 与「本地优先、不联网」的定位冲突 |
| 刷新后恢复标签页 | 需要把文件句柄持久化到 IndexedDB，已实现（v1.2） |
| Safari / Firefox 的文件监听 | 浏览器能力缺失，只能降级为手动刷新 |

## 4. 功能需求与验收标准

| 编号 | 需求 | 验收标准（可观测） | 状态 |
| --- | --- | --- | --- |
| FR-1 | 打开单个文件 | 拖入 `x.md` 或点「打开文件」后，正文在 1 秒内出现 | ✅ |
| FR-2 | 打开整个目录 | 选择目录后列出全部 `.md`，按目录分组，并自动打开第一篇 | ✅ |
| FR-3 | **打开文件夹只收 .md** | 目录里的 `.txt`、`.png`、`node_modules` 不出现在文件列表 | ✅ |
| FR-4 | CommonMark 渲染 | 标题 / 段落 / 列表 / 引用 / 代码 / 分隔线 / 链接 / 图片结构正确 | ✅ |
| FR-5 | GFM 扩展 | 表格（含 `:--:` 对齐）、任务列表、删除线、自动链接、脚注 | ✅ |
| FR-6 | 代码块 | 常用语言高亮；未标注语言原样显示；一键复制 | ✅ |
| FR-7 | Mermaid 图表 | ` ```mermaid ` 渲染成图；语法错误有提示不白屏 | ✅ |
| FR-8 | **KaTeX 公式** | 行内 `$…$` 与块级 `$$…$$` 渲染成公式；`$5 和 $6` 这类金额不被误判 | ✅ |
| FR-9 | 相对图片 | 目录模式下 `![](./img/a.png)` 能显示；失败时给占位框 | ✅ |
| FR-10 | 大纲 | 列出 h1–h4；滚动高亮跟随；点击跳转 | ✅ |
| FR-11 | 阅读偏好 | 主题 / 字号 / 宽度可切换，刷新后保持 | ✅ |
| FR-12 | 粘贴预览 | 粘贴文本后立即渲染，不写入任何文件 | ✅ |
| FR-13 | 安全净化 | `<script>`、`onerror`、`javascript:` 链接都不生效 | ✅ |
| FR-14 | **多标签页** | 依次打开 3 篇文档 → 出现 3 个标签；切换回去时滚动位置与内容都保留 | ✅ |
| FR-15 | **标签关闭** | 关闭当前标签后自动激活相邻标签；关闭最后一个回到空状态 | ✅ |
| FR-16 | **文件监听** | 用编辑器改文件并保存 → 1 秒内预览自动更新，滚动位置不跳 | ✅ |
| FR-17 | **保存回写** | 双栏模式下 `Ctrl/⌘+S` 保存到原文件；未保存时标签显示脏点 | ✅ |
| FR-18 | **双栏同步滚动** | 滚动任一侧，另一侧跟随到大致相同的段落 | ✅ |
| FR-19 | **刷新后恢复会话** | 打开目录里的文档并滚动到中部 → 刷新页面 → 标签与滚动位置自动恢复 | ✅ |
| FR-20 | **批量关闭** | 标签条右侧「⋯」→「关闭其他标签」只剩当前；「全部关闭」回到空状态 | ✅ |
| FR-21 | **授权过期处理** | 浏览器重启导致权限失效时，顶部出现「恢复」条，点一下即可重新授权并打开 | ✅ |
| FR-22 | **桌面版双击运行** | 打包后双击 exe 直接出现窗口，不经过浏览器 | ✅ |
| FR-23 | **双击 .md / 命令行打开** | 关联后双击文档直接打开；重复启动复用同一个窗口 | ✅ |

## 5. 非功能需求

| 类别 | 要求 | 实测 / 现状 |
| --- | --- | --- |
| 启动速度 | 打开页面到看到内容 ≤ 1.5 s | 首次内容绘制 180 ms |
| 首屏体积 | ≤ 250 KB（gzip） | 180.5 KB（JS 175.6 + CSS 4.9） |
| 按需体积 | 公式与图表不进首屏 | KaTeX 9.5 KB（CSS 7.8 + JS 1.7 拆分块）按需加载，字体命中才下载 |
| 常规文档 | 16 万字符无感 | 85 ms |
| 大文档 | 2 MB 左右 ≤ 1 s | 464 ms |
| 极端文档 | 不白屏、不崩溃 | 18 万 DOM 节点约 10 s（见第 7 节） |
| 监听开销 | 不得造成明显卡顿 | 每 900 ms 只对「已打开的标签」读一次 `lastModified` |
| 运行环境 | 纯静态，无服务端、无遥测 | 符合 |
| 隐私 | 文件内容不离开本机 | 符合；写回只在用户按保存时发生 |
| 浏览器 | Chrome / Edge 完整能力；Safari 16+ / Firefox 115+ 基础预览 | Chrome 完整验证；其余降级路径未逐个回归 |

## 6. 验收结果

验证方式：`pnpm build`（含 `tsc --noEmit`）+ Chrome DevTools Protocol 脚本断言（`tools/shot.mjs`）。

| 检查项 | 结果 |
| --- | --- |
| 构建与类型检查 | 通过 |
| 示例文档渲染 | 表格 / 任务列表 / 代码块 / Mermaid / 公式 全部命中 |
| 公式精度 | 3 个公式节点；`$5 和 $6` 保持原文 |
| 目录扫描（模拟句柄） | 只返回 `README.md`、`guide/install.md`；`.txt`、`.png`、`node_modules` 被跳过 |
| 多标签 | 打开第二篇后标签数 2；切回第一篇滚动位置恢复到 1200 |
| 双栏同步 | 编辑器滚到 1400 → 预览 1642；预览回顶 → 编辑器回 12 |
| 会话恢复 | 刷新后标签恢复为 `Demo.md`，滚动位置精确回到 900 |
| 批量关闭 | 2 个标签 →「关闭其他」剩 1 个 →「全部关闭」剩 0 个并回到空状态 |
| 桌面版启动 | 双击 exe 出现窗口；带 `.md` 参数启动时该文件成为当前标签 |
| 桌面版保存 | 双栏修改后保存，磁盘文件内容同步更新 |
| 控制台错误 | 0 |

## 7. 已知限制

| 限制 | 说明 / 计划 |
| --- | --- |
| 拖拽/普通选择器打开的文档不能监听，也不进会话 | 网页版只能拿到快照 `File`；桌面版按路径打开没有这个问题 |
| Safari / Firefox 无目录句柄 | 网页版自动降级为手动刷新，保存按钮不可用 |
| 单文件模式解析不了相对图片 | 网页版需要目录上下文；桌面版按绝对路径解析 |
| 极端大文档（约 18 万 DOM 节点）约 10 s | 分块渲染留待后续 |
| 桌面版体积约 337 MB | Electron 运行时占绝大部分；要十几 MB 只能换 Tauri |
| 桌面版无代码签名 | Windows SmartScreen 会提示，需手动放行 |
| 无自动化 UI 测试 | 目前依赖构建期类型检查 + CDP 断言 |
