# 桌面版

> 目标：**双击就能用**，不经过浏览器、不需要先跑 `pnpm dev`。

![桌面版窗口](../assets/screenshot-desktop.png)

## 1. 两种双击

| 双击什么 | 结果 |
| --- | --- |
| `MarkdownPreview.exe` | 打开预览器，恢复上次的标签；也可以从菜单或拖拽打开文档 |
| 任意 `.md` 文件 | 用预览器打开它（需先做一次文件关联，见第 5 节） |

把 `.md` 文件直接拖到 exe 图标上，效果等同于双击；第二次启动会复用已经开着的窗口。

## 2. 构建

```bash
pnpm install
node node_modules/electron/install.js   # pnpm 10 默认不执行构建脚本，Electron 二进制要手动装
pnpm dist                               # = tsc + vite build + 打包 Electron
```

> 第一次装完如果直接 `pnpm dist` 报「找不到 Electron 运行时」，就是漏了第二行。

产物：

```
release/MarkdownPreview/
├─ MarkdownPreview.exe     ← 双击这个
├─ 使用说明.txt
├─ resources/
│  ├─ app/                 ← 我们的界面与主进程
│  └─ ...
└─ *.dll / locales / ...
```

整个文件夹可以拷到任意位置或 U 盘，**不需要安装**；体积约 **337 MB**（Electron 运行时占绝大部分）。

开发调试（不打包，直接跑）：

```bash
pnpm build && pnpm desktop      # 用当前 dist/ 启动
```

## 3. 为什么是 Electron

| 方案 | 双击可用 | 依赖 | 代价 |
| --- | --- | --- | --- |
| **Electron** | 是 | 只需 npm | 运行时约 300 MB |
| Tauri | 是 | 需要 Rust 工具链 + MSVC | 产物 ~10 MB，但本机没有 Rust，装一次要几百 MB 且要等编译 |
| PWA | 否（仍然在浏览器里） | — | 无法接管 `.md` 的双击 |

选 Electron 的关键原因不是体积，而是**这一版的核心诉求从「打开快」变成了「双击就能进」**：用户不再经过浏览器地址栏，所以需要一个原生进程、原生菜单和文件关联能力。体积的代价是明确的，写在明面上。

> 想回到轻量版，网页版仍然完整保留：`pnpm dev` 或把 `dist/` 放到任意静态服务器。

## 4. 结构

```
electron/
├─ main.cjs      主进程：窗口、菜单、文件系统 IPC、命令行参数、单实例
└─ preload.cjs   预加载：把有限的文件能力挂到 window.desktop
src/lib/desktop.ts   界面侧适配：把 window.desktop 包装成 Library
scripts/package-desktop.mjs   打包脚本（复制运行时 + 放 app）
scripts/associate-md.ps1      文件关联（写 HKCU，可撤销）
```

界面代码一行都没为桌面版改动：`Library` 这层抽象把「浏览器句柄」和「本地路径」都吃掉了，只是多了一个实现。

### IPC 一览

| 通道 | 作用 |
| --- | --- |
| `dialog:openFile` / `dialog:openFolder` | 原生文件/目录选择框 |
| `fs:scan` | 递归扫描目录，只返回 `.md` |
| `fs:read` / `fs:write` / `fs:stat` / `fs:exists` | 读写与元信息 |
| `app:initial` | 启动参数里的文件（命令行 / 双击关联） |
| `fs → app:open-files` | 菜单打开、第二个实例传入的文件 |
| `shell:reveal` | 在资源管理器中定位文件 |

安全边界：渲染进程拿不到 Node，`contextIsolation: true`，`nodeIntegration: false`，只有 preload 暴露的那几个方法。

## 5. 关联 .md（可选）

只写当前用户的注册表（HKCU），不需要管理员：

```powershell
# 只加进「打开方式」列表，不改默认程序
pwsh -File scripts\associate-md.ps1

# 直接把 .md 的默认程序设成预览器（会备份原来的默认值）
pwsh -File scripts\associate-md.ps1 -SetDefault

# 撤销（含恢复原来的默认程序）
pwsh -File scripts\associate-md.ps1 -Undo
```

做完之后，资源管理器里双击 `.md` 就会直接打开预览器。

## 6. 与网页版的差异

| 能力 | 网页版 | 桌面版 |
| --- | --- | --- |
| 打开文档 | 拖拽 / 选择器 / 目录授权 | 同样支持，另加命令行参数与文件关联 |
| 自动刷新 | 需要目录句柄授权 | **直接按路径监听**，不需要授权 |
| 保存 | 需要读授权 | 直接写盘 |
| 刷新后恢复 | 句柄存 IndexedDB，重启浏览器要重新授权 | **按绝对路径恢复**，无需授权 |
| 站外链接 | 当前页新开标签 | 交给系统默认浏览器 |
| 菜单 / 快捷键 | 浏览器菜单 | 原生菜单（`Ctrl+O` 打开文件等） |

## 7. 常见问题

**双击 exe 没反应？**
先确认系统环境变量里没有 `ELECTRON_RUN_AS_NODE=1`——它的存在会让 Electron 退化成纯 Node 运行，窗口不会出现。可以在命令行里 `set ELECTRON_RUN_AS_NODE=` 之后重试；如果是系统级设置的，建议删掉这一项。

**Windows 提示「已保护你的电脑」？**
这是 SmartScreen 对未签名程序的默认提示，点「更多信息 → 仍要运行」。签名需要代码证书，不在本项目范围内。

**体积能小一点吗？**
可以：用 `electron-builder` 或 `@electron/asar` 压缩资源、删掉 `locales` 里用不到的语言；但运行时的主体（~300 MB）省不掉。要十几 MB 只能用 Tauri。

**双击 .md 还是用旧程序打开？**
说明默认程序没改成预览器。用 `-SetDefault` 再跑一次，或者右键 → 打开方式 → 选择其他应用。

**怎么卸载？**
删掉 `release/MarkdownPreview` 文件夹；如果做过关联，先跑一次 `associate-md.ps1 -Undo`。
