## 5. 可重复的自查

检查过程固化成了一个脚本，随时可以再跑一遍（也方便贡献者自查）：

```bash
pnpm scan          # = node tools/scan-secrets.mjs
```

它扫描 11 类特征：本机用户目录、开发机路径、macOS/Linux 家目录、Windows 安装路径、环境变量、凭据赋值、常见令牌格式、Bearer 头、私钥区块、邮箱地址。

脚本本身做过自检：故意写入一条假令牌和一条 Windows 用户目录路径，能全部报出来；清理后恢复 `CLEAN`。

## 6. 发布前清单

```bash
# 1. 确认被忽略的目录不会被提交（应只列出源码与文档）
git add -A --dry-run

# 2. 确认没有敏感文件
git status --short

# 3. 提交
git commit -m "feat: Markdown 预览器 v1.3（Web + 桌面）"

# 4. 关联远端并推送
git remote add origin <你的仓库地址>
git push -u origin main
```

已经验证：`git add -A --dry-run` 输出 **70 个文件**，`node_modules/`（633 MB）、`dist/`（6.7 MB）、`release/`（337 MB）全部被排除。

## 7. 运行时会写哪些本机数据

开源说明里建议声明清楚，方便使用者自己清理：

| 位置 | 内容 | 清理方式 |
| --- | --- | --- |
| 浏览器 `localStorage` | 主题、字号、阅读宽度 | 清除站点数据 |
| 浏览器 `IndexedDB`（库 `md-preview`） | 上次打开的文件句柄、滚动位置 | 同上 |
| 桌面版 `%APPDATA%\Markdown 预览器` | 窗口状态、Electron 缓存、上述 IndexedDB | 删除该文件夹 |

应用**不联网、不上报**：Mermaid、KaTeX、highlight.js 全部随包构建，运行时不请求任何远程资源；站外链接交给系统浏览器打开。
