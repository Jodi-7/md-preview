## 2. 模块职责

| 模块 | 职责 | 对外接口 | 不该做的事 |
| --- | --- | --- | --- |
| `lib/files.ts` | 把各种文件来源收敛成 `Library` | `libraryFromFiles` / `libraryFromDirectoryHandle` / `libraryFromFileHandle` / `libraryFromText` | 不碰 React，不碰样式 |
| `lib/markdown.ts` | 文本 → 安全 HTML | `renderMarkdown` / `slugify` / `countWords` | 不做 DOM 增强 |
| `lib/scrollSync.ts` | 行 ↔ 像素的换算 | `measureLineOffsets` / `lineAtOffset` / `scrollPreviewToLine` / `previewLineAtTop` | 不碰事件 |
| `lib/useScrollSync.ts` | 绑定滚动事件与节流锁 | `useScrollSync(options)` | 不改内容 |
| `lib/session.ts` | 会话落盘与恢复 | `loadSession` / `saveSession` / `ensureReadPermission` | 不碰 React 状态 |
| `lib/desktop.ts` | 桌面版文档库（走 IPC） | `libraryFromDesktop` / `desktopBridge` | 不做浏览器降级分支 |
| `components/Editor.tsx` | 编辑与量尺 | props + `onChange` / `onSave` | 不解析 Markdown |
| `components/DocumentView.tsx` | HTML → 可交互页面 | props + 两个回调 | 不读文件、不解析 |
| `App.tsx` | 状态机、标签页、监听、事件 | — | 不写业务算法 |

## 3. 核心接口

### 3.1 `Library`（文件来源）

```ts
interface Library {
  kind: 'single' | 'directory' | 'demo'
  rootName: string
  docs: DocEntry[]
  watchable: boolean                        // 只有句柄来源为 true
  readDoc(path: string): Promise<string>
  resolveAsset(docPath: string, src: string): Promise<string | null>
  stat?(path: string): Promise<DocStat | null>     // 监听用
  writeDoc?(path: string, text: string): Promise<void>  // 保存用
  dispose(): void
}
```

约定：`path` 是库内相对路径，永远 `/` 分隔；`readDoc` 失败要抛错；换库时必须 `dispose()`，否则 blob URL 泄漏。

### 3.2 `Tab`（打开中的文档）

```ts
interface Tab {
  id: string; path: string; name: string; rootName: string
  lib: Library
  text: string; savedText: string; html: string; mtime: number
  read(): Promise<string>
  stat?(): Promise<DocStat | null>
  write?(text: string): Promise<void>
}
```

标签自带闭包，所以即使之后又打开了别的目录，旧标签仍然可用。

## 4. 渲染的六个阶段

`DocumentView` 里按顺序发生，任何一件失败都不影响其余：

| # | 阶段 | 依赖 | 产物 |
| --- | --- | --- | --- |
| 1 | 生成 HTML | `renderMarkdown()`（在 App 中调用） | 净化后的 HTML |
| 2 | 注入 DOM | `dangerouslySetInnerHTML` | 静态正文 |
| 3 | 挂复制按钮 | `html` | 每个 `pre.hljs` 增加按钮 |
| 4 | 解析相对图片 | `html/docPath/library` | `img.src` 换成 blob URL |
| 5 | 渲染 Mermaid | `html/dark` | `pre.mermaid-src` → SVG |
| 6 | 渲染公式 | `html` | `.math-*[data-tex]` → KaTeX |
| 7 | 采集大纲 | `html` | `OutlineItem[]` |

## 5. 踩坑记录

这些是实际写代码时踩到的，改代码前值得先看一遍。

**`webkitGetAsEntry()` 只在同步阶段有效。**
必须先把所有 `DataTransferItem` 的 entry 同步取出，再 `await`；先 await 再取永远是 `null`。

**`readEntries()` 每次最多返回 100 条。**
必须循环读到空数组，否则大目录只导入前 100 个文件。

**`markdown-it` 的 highlight 回调要返回整段 `<pre>`。**
返回字符串以 `<pre` 开头时渲染器才原样采用；否则会再包一层 `<pre><code>`。
副作用：这样一来 token 上的属性全被忽略，所以 `data-line` 只能在 fence 渲染结果里用字符串替换补进去。

**表格对齐会带出内联 style。**
markdown-it 用 `style="text-align:center"`，与「禁止 style」冲突。解法是在 `th_open` / `td_open` 里搬成 class 并删除属性。

**DOMPurify 默认会丢掉 `data-*` 和 `blob:` 图片。**
所以：`ALLOW_DATA_ATTR: true`（行号与公式需要），图片则在挂载后再改 `img.src`。

**textarea 的软换行让「行号 → 像素」不再线性。**
用镜像 `div` 量：同字体、同行高、同宽度，每个源码行一个子元素，读 `offsetTop`。
镜像宽度必须用 `clientWidth - paddingLeft - paddingRight` 算，否则 textarea 的滚动条会把换行点推歪。

**双向同步会互相弹。**
用一个 120 ms 的「驱动锁」：A 驱动 B 时上锁，锁内的滚动事件直接忽略。

**React StrictMode 会让 Mermaid 渲染两次。**
开发模式下 effect 执行两遍，Mermaid 会因重复 id 报错。当前没启用 StrictMode；要开需给 effect 加幂等保护。

**快速连点会串台。**
`openTab` 用 `tabsRef` 判重，并且只有真正读到内容才 push 新标签。

**`$` 公式会吃进代码区。**
`$5 和 $6 不会被…`$`…` 这种文本里，收尾的 `$` 可能落在反引号里。规则补了两条：收尾 `$` 后面不能是数字、公式内容里不能出现反引号。

**滚动位置不会自己触发持久化。**
写库的 effect 依赖是 `[tabs, activeId]`，而滚动只改 ref（不触发渲染）。所以额外监听 `pagehide` 与 `visibilitychange`，在页面隐藏前再存一次——否则刷新后滚动位置永远停在旧值。

**`FileSystemHandle` 能存进 IndexedDB，但授权不能。**
句柄本身是结构化可克隆的，直接 `put` 即可；但 `requestPermission` 需要用户手势。所以恢复失败时不静默丢弃，而是攒成一条「恢复」提示，把授权动作留给用户点击。

**恢复时不要逐个文件新建 Library。**
按 `kind + rootName` 分组，每组只扫一次目录，然后把组内的标签逐个 `openTab`；否则 N 个标签会触发 N 次目录全量扫描。

**命令行传入的文件会被会话恢复顶掉。**
`did-finish-load` 里推送文件的事件、和 IndexedDB 会话恢复，两条异步链谁先完成不确定。解法是两条路径都 `await restorePromise`，再加一个 `pendingFocus` 在标签变化后把「刚点开的文件」重新置前。

**`ELECTRON_RUN_AS_NODE=1` 会让桌面版直接退出。**
这个环境变量存在时，Electron 退化成纯 Node：`require('electron')` 返回路径字符串，`ipcMain` 是 undefined，或者干脆把 `.md` 当脚本执行。调试脚本里必须把它删掉再 spawn。

**打包不需要 electron-builder。**
Electron 只要求 exe 同级有 `resources/app`（含 `package.json` 与 `main`）。复制 `node_modules/electron/dist` 过去、把界面放进 `resources/app` 就够了，省掉一整套下载依赖。

## 7. 修改指南

| 想做的事 | 改哪里 | 注意 |
| --- | --- | --- |
| 加 Markdown 插件 | `lib/markdown.ts` 的 `md.use(...)` | 注意插件是否读写 `style` |
| 换代码高亮配色 | `styles/markdown.css` 的 `.hljs-*` | 代码块固定深底，两套主题共用 |
| 调整同步手感 | `lib/useScrollSync.ts` 的 `guard` 时长 | 太短会抖，太长会拖 |
| 改监听频率 | `App.tsx` 的 `WATCH_INTERVAL` | 别低于 500 ms |
| 标签页跨刷新保留 | 在 `App` 里把句柄写进 IndexedDB | 恢复时要处理授权状态 |
| 编辑器换成 CodeMirror | 替换 `components/Editor.tsx` | 保留 `textareaRef` + `mirrorRef` 两个接口即可 |
| 改空状态文案 | `components/EmptyState.tsx` | 保持「能干什么 + 怎么开始」结构 |

## 8. 验证方式

没有引入测试框架，用两个轻量手段代替：

1. **构建即校验**：`pnpm build` 先跑 `tsc --noEmit`，类型错误直接中断。
2. **浏览器断言**：`tools/shot.mjs` 用 Chrome DevTools Protocol 打开页面、执行表达式、截图，并收集控制台错误。

```bash
# 公式与结构
node tools/shot.mjs "http://127.0.0.1:5180/?demo=1" out.png 1440 960 \
  "({math:document.querySelectorAll('.katex').length,tables:document.querySelectorAll('.md-body table').length})"

# 双栏 + 同步
node tools/shot.mjs "http://127.0.0.1:5180/?demo=1" split.png 1440 960 \
  "(async()=>{document.querySelector('.toolbar-actions .icon-btn').click();await new Promise(r=>setTimeout(r,300));const ta=document.querySelector('.editor-input');ta.scrollTop=1400;ta.dispatchEvent(new Event('scroll'));await new Promise(r=>setTimeout(r,200));return{preview:document.querySelector('.content').scrollTop}})()"

# 深色 / 移动端
node tools/shot.mjs "http://127.0.0.1:5180/?demo=1" dark.png 1440 960 "" --dark
node tools/shot.mjs "http://127.0.0.1:5180/?demo=1" mobile.png 414 900 ""
```

会话恢复要跨两次加载才能验证，用 `--profile=` 复用同一个浏览器配置目录：

```bash
# 第一次：打开示例，等会话落盘
node tools/shot.mjs "http://127.0.0.1:5180/?demo=1" a.png 1440 900 "" "--profile=$TEMP/mdp"
# 第二次：不带参数重新打开，标签应当自动回来
node tools/shot.mjs "http://127.0.0.1:5180/" b.png 1440 900 \
  "({tabs:[...document.querySelectorAll('.doc-tab-name')].map(e=>e.textContent)})" "--profile=$TEMP/mdp"
```

开发模式下 `window.__mdp` 暴露了 `lib/files.ts` 的函数，可以直接用假句柄验证目录扫描：

```js
const root = { kind:'directory', name:'docs', values: async function*(){ /* … */ } }
const lib = await window.__mdp.libraryFromDirectoryHandle(root)
lib.docs.map(d => d.path)   // 只会包含 .md
```

## 9. 已知限制

- 拖拽 / 粘贴打开的标签不进会话，刷新后消失
- Safari / Firefox 拿不到目录句柄，监听与保存不可用
- 单文件模式没有目录上下文，相对图片解析不了
- 极端文档（约 18 万 DOM 节点）渲染到 10 秒量级
- 没有自动化 UI 测试，只有构建期类型检查 + 手动 CDP 断言
