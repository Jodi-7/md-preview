Markdown 预览器

把 .md 文件或整个文档目录拖进来，立刻看到渲染结果。不上传、不落盘，全部在本地完成。

渲染遵循 CommonMark 规范，并启用 GFM 扩展；原始 HTML 会在渲染后经过白名单净化，脚本类内容不会执行。

快速开始

# 三条命令跑起来
pnpm install
pnpm dev        # http://localhost:5180
pnpm build      # 产出 dist/

支持的语法

能力状态说明

GFM 表格与任务列表已支持表头对齐生效
代码高亮已支持常用语言内置
Mermaid 图表已支持命中时才加载

这是一份静态原型：布局、信息层级与交互状态与实现一致，但不包含真实的解析逻辑。
